O｜长期伴侣核心互动模式
模式 01｜“伴侣变成室友”
条件：
coexisting_without_connection 高
partner_to_roommate_shift 高
couple_time_need 高
解释：
关系的问题可能不是生活合作失败。
恰恰相反，你们可能非常会合作。
真正减少的是：
两个人作为伴侣，而不是家庭团队成员的连接。
模式 02｜“看不见的劳动不平衡”
条件：
mental_load_awareness 高
manager_partner_dynamic 高
解释：
一个做的是看得见的任务。
另一个除了做任务，还负责：
发现问题、记住时间、安排顺序、提醒别人。
双方可能都觉得自己做了很多，但疲惫来源并不相同。
模式 03｜“一个人负责家庭情绪”
条件：
household_emotional_load 高
emotion_dominates_household 高
解释：
一个人的情绪容易成为整个家庭的天气。
另一个人慢慢承担了调节氛围、安慰、避免冲突的责任。
模式 04｜“修复很多次，但没有结构变化”
条件：
repair_without_change_fatigue 高
structural_repair_need 高
解释：
你们未必不会和好。
真正的问题可能是：
和好以后，导致矛盾的系统又恢复原样。
模式 05｜“父母边界没有形成夫妻共同体”
条件：
couple_boundary_with_parents 高
extended_family_balance 冲突
解释：
关系真正的矛盾可能不在父母，而在：
面对原生家庭压力时，你有没有感觉伴侣和你是一个团队。
模式 06｜“家庭公平定义不同”
A：
认为公平 = 做一样多。
B：
认为公平 = 根据收入、能力、时间弹性分工。
解释：
双方都可能觉得自己追求公平，只是对“公平”的定义不同。
模式 07｜“工作贡献被当作爱，陪伴缺失被当成忽视”
一方：
“我努力工作就是为了这个家。”
另一方：
“可是这个家几乎没有你的时间。”
这是非常重要的一种长期关系模式。
模式 08｜“高自主 × 高承诺”
解释：
想保留自己的兴趣、朋友和时间，并不等于不愿意长期承诺。
有些人真正理想的长期关系是：
两个完整的人，共享生活，而不是逐渐合并成一个人。
模式 09｜“共同育儿，但默认家长只有一个”
条件：
default_parent_load 高
解释：
两个人可能都非常爱孩子。
但真正的负担差异可能出现在：
谁记得体检？
谁和老师联系？
谁知道家里尿不湿还有多少？
谁始终是第一个被找的人？
模式 10｜“关系不是缺爱，而是缺重新认识”
条件：
关系时间长
growth_alignment_need 高
解释：
两个人可能非常了解过去的彼此，
却没有发现：
几年以后，身边这个人已经发生了新的变化。
P｜长期伴侣报告中的高价值句型
句型 01
长期关系最容易失去的，不一定是爱，而是对彼此继续保持好奇。
句型 02
“我每天都在为这个家做很多事情”和“我感觉不到自己被爱”，可以同时是真的。
句型 03
很多家庭矛盾表面上在争家务，实际上争的是：我的时间和疲惫有没有被你看见。
句型 04
家务里最容易被忽略的部分，不是执行，而是发现、记住、计划和提醒。
句型 05
关系里的公平不一定意味着五五分，而是双方都认为自己的负担被理解、被认可。
句型 06
真正消耗人的，有时不是一次严重冲突，而是同一个问题经过很多次道歉以后仍然原样回来。
句型 07
成为父母以后，你们需要经营的不只是“爸爸和妈妈”的合作，也包括两个人仍然是不是彼此的伴侣。
句型 08
长期关系的亲密，不只是知道对方昨天做了什么，而是仍然知道对方最近在想什么。
句型 09
真正成熟的边界不是“你的父母还是我的父母”，而是面对外部压力时，两个人能不能先成为一个团队。
句型 10
有些关系不是输在没有感情，而是生活系统越来越复杂以后，感情永远被排在最后处理。

R｜程序特别规则
长期伴侣题库必须先读取用户背景。
例如：
has_children = false
则：
禁止：
MAR-CU-03
MAR-X-09
MAR-X-10
MAR-X-11
如果：
living_together = false
则：
减少家务、同居场景题权重。
如果：
shared_finances = false
则：
金钱题可以问价值观，
但不优先问：
共同账户、家庭预算。
如果：
married = false
所有文案统一使用：
“伴侣 / TA”。
不要自动出现：
“丈夫 / 妻子”。
S｜长期伴侣报告的一条重要安全规则
如果用户回答涉及：
长期控制、
恐吓、
暴力、
强迫、
经济控制、
跟踪监视等情况，
系统不要继续把它解释成：
“你们沟通方式不同。”
这类情况需要脱离普通“默契分析”。
产品应该显示更谨慎的提示：
某些关系问题可能已经超出普通沟通差异的范围。
如果你感到人身安全、自由或基本生活受到威胁，优先考虑现实安全与可信赖的专业支持。
不要用匹配分数弱化严重关系风险。
T｜下一块题库
现在已经完成：
异地恋
长期伴侣 / 已婚
下一项：
关系紧张 / 正在考虑是否继续
这一套会非常重要。
因为这类用户真正想知道的不再是：
“我们合不合？”
而是：
“我们现在的问题，到底还有没有修复空间？”
它必须重点测：
失望累积
信任下降
情绪撤离
沟通疲劳
重复冲突
是否仍有修复意愿
是否仍然愿意理解对方
是否只剩责任
是否开始想象没有 TA 的生活
是否还有共同未来
修复到底缺“方法”还是缺“意愿”
双方是否都在努力
是暂时疲惫还是长期结构性问题
这会是付费报告价值非常高的一套题库。
